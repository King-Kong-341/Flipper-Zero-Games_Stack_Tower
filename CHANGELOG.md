# Changelog

## 1.0 — 2026-09-30

First release.

- Faithful Stack gameplay: sliding slabs on alternating axes, slicing,
  perfect drops, grow-back after 8 perfects in a row, speed ramp
- Isometric 3D software renderer (40 fps) with falling pieces, rising camera
  and game-over zoom-out showing the whole tower
- Intro animation, live title screen with an autopilot tower
- Pause menu, game-over panel with best score / new best
- Settings: sound, volume, vibration, LED, background (Day / Dots / Night), intro
- Stats: best, games, slabs, perfects, best streak, average, perfect rate
- How-to-play pages with animated demos
- Sound, vibration and RGB LED feedback for every event
